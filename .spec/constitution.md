# Project Constitution

## Non-Negotiable Core Rules
1. **Code Standards**: Adhere strictly to clean code practices, modular design, and robust typing.
2. **Security**: Zero hardcoded secrets, strict input validation, and no unauthenticated sensitive endpoints.
3. **Verification**: No feature is complete without automated test verification passing cleanly.
4. **Code Graph Query**: Use `@colbymchenry/codegraph` (`codegraph index/query`) before writing code.
