# Grill With Docs Protocol

Run a `grilling` session, while continuously updating and capturing:
1. `adr.md` (Architecture Decision Records) for technical decisions settled during the interview.
2. `domain-glossary.md` (Domain Vocabulary) for business terms, domain concepts, and boundaries defined during the interview.
